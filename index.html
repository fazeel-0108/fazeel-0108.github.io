about

Curious by default.

I’m Fazeel Abdur Rahman Khan, a Computer Science diploma student at Quli Qutub Shah Government Polytechnic, Hyderabad. It all started at Little Century High School, where I was less interested in using a computer and more curious about what’s going on inside it.

Along the way I taught myself web development with Python, JavaScript, HTML and CSS, picked up C, C++ and Data Structures from my coursework, and keep it all organized with Git and VS Code. Most of what I know came from building small things, breaking them, then fixing them.

Off the keyboard, I’m usually reading about hardware, networking and cybersecurity — I genuinely enjoy understanding how machines talk to each other. The biggest thing I’ve built so far is a voice assistant I actually talk to every day. The next one? Still sketching it out.
